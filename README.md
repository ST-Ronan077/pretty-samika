# Pretty Samika — Digital Flower Gift

A free, static digital love-letter website inspired by the interaction flow of modern digital flower gifts.

## Included flow

1. 4-digit lock
2. Personalized intro
3. Animated bouquet
4. Long romantic note
5. YouTube song button
6. Final surprise

## Customize

Open `script.js` and change:
- `entered === "0315"` for the lock code
- `songUrl` for the song

Open `index.html` and edit:
- Shrawan / Pretty Samika
- the romantic message
- final text
